So this week was a free design, But I was a little busy so I decided to follow the guide of the LoRa Puck.(though I wished I did the keyboard)
So I just followed the guide for the most part, But I did have some issues finding the symbols in the schematic.
When that issue occured, I just created my own by following a guide online and it seems to have worked quite well.

The main purpose of the lora (LOng RAnge) puck is to wirelessly communicate information through radio waves. This is why the schematic has the AE1 Antenna.
Without the use of wifi, celluar, and bluetooth, the lora puck is able to transfer information, such as temperature, motion, and more.
It uses a long lasting battery which makes it more reliable in situations where wifi isn't avaliable.
